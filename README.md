# GCSRM Task 1 — F1 Lap Time Predictor

Open `F1_Lap_Time_Predictor_Final.ipynb` in Google Colab, upload the four required CSV files, and run the notebook from top to bottom.

Required files:
- lap_times.csv
- pit_stops.csv
- results.csv
- races.csv

The notebook uses the 2019 Spanish Grand Prix, selects up to 8 finishers with multiple stints, removes pit/out-laps and slow outliers, performs a stint-based split, and compares Linear Regression and Random Forest with and without tire age.
